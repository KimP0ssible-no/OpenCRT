OpenCRT packages

Set up the repository once; after that OpenCRT updates with the rest of the system. Other platforms and every release: github.com/KimP0ssible-no/OpenCRT/releases.

Signing key fingerprint: @FINGERPRINT@

Debian, Ubuntu

sudo install -d /etc/apt/keyrings
curl -fsSL @URL@/opencrt.asc | sudo tee /etc/apt/keyrings/opencrt.asc > /dev/null
echo "deb [signed-by=/etc/apt/keyrings/opencrt.asc] @URL@/apt stable main" | sudo tee /etc/apt/sources.list.d/opencrt.list
sudo apt update && sudo apt install opencrt

Fedora, RHEL, Rocky, Alma

sudo curl -fsSL -o /etc/yum.repos.d/opencrt.repo @URL@/rpm/opencrt.repo
sudo dnf install opencrt

openSUSE

sudo zypper addrepo @URL@/rpm/opencrt.repo
sudo zypper install opencrt

Arch Linux

curl -fsSL @URL@/opencrt.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key @FINGERPRINT@
printf '\n[opencrt]\nServer = @URL@/arch\n' | sudo tee -a /etc/pacman.conf
sudo pacman -Syu opencrt
